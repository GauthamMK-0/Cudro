## 1. Architectural Purpose
The projection kernel needs **Jacobians** ∂g/∂q for every constraint g(q). Instead of manual differentiation or finite differences, we implement a **forward-mode automatic differentiation (AD) pass** over the Expression DAG.

### Why Forward-Mode AD?
| Mode | Best For | Our Case |
|---|---|---|
| Forward | #outputs ≥ #inputs | Constraints (outputs) ≤ DoFs (inputs) |
| Reverse | #inputs > #outputs | Neural nets (1 loss, millions of weights) |

Our constraints: ~1-5 outputs per constraint, 7-28 DoFs → **forward-mode wins** (simpler, no tape needed).

## 3. Forward-Mode AD Theory

### Dual Numbers
A **dual number** is a pair `(v, ḋv)` where:
- `v` = primal value
- `ḋv` = derivative w.r.t. some seed

Arithmetic propagates derivatives via the chain rule:
```
(u + v)' = u' + v'
(u * v)' = u' * v + u * v'
sin(u)' = cos(u) * u'
```

### Arbitrary Rotation Axis (`RotAxis`) Rodrigues Differentiation
For a revolute joint rotating by angle $\theta$ around an arbitrary spatial unit axis $\hat{k} = (a_x, a_y, a_z)^T$, the rotation matrix is given by Rodrigues' formula:
$$R(\hat{k}, \theta) = \cos\theta \mathbf{I} + (1 - \cos\theta) \hat{k}\hat{k}^T + \sin\theta [\hat{k}]_\times$$
where $[\hat{k}]_\times$ is the skew-symmetric matrix of $\hat{k}$.

When differentiating with respect to joint variable $q_j$ (where $\theta = q_j$):
$$\frac{\partial R}{\partial q_j} = -\sin\theta \mathbf{I} + \sin\theta \hat{k}\hat{k}^T + \cos\theta [\hat{k}]_\times$$
In `src/ad.cpp`, this exact analytical matrix derivative is constructed symbolically via DAG nodes, avoiding any finite-difference approximations for compound spatial skew axes.

## 4. Multi-Constraint Jacobian Matrix Assembly

For an arbitrary system with $M$ constraints $\{g_0(q), g_1(q), \dots, g_{M-1}(q)\}$ and $N$ degrees of freedom $\{q_0, \dots, q_{N-1}\}$, the full analytical Jacobian is the $M \times N$ matrix:
$$J(q) = \begin{bmatrix}
\frac{\partial g_0}{\partial q_0} & \cdots & \frac{\partial g_0}{\partial q_{N-1}} \\
\vdots & \ddots & \vdots \\
\frac{\partial g_{M-1}}{\partial q_0} & \cdots & \frac{\partial g_{M-1}}{\partial q_{N-1}}
\end{bmatrix}$$

`build_analytical_jacobians` runs forward passes seeded by each input $j \in [0, N-1]$:
```cpp
std::vector<std::vector<int>> build_analytical_jacobians(ExprDAG& dag, const std::vector<int>& constraint_outputs, int num_inputs) {
    int num_constraints = static_cast<int>(constraint_outputs.size());
    std::vector<std::vector<int>> jacobian_nodes(num_constraints);

    for (int j = 0; j < num_inputs; ++j) {
        auto active = compute_activity(dag, j);
        std::unordered_map<int, int> cache;
        for (int c = 0; c < num_constraints; ++c) {
            if (jacobian_nodes[c].empty()) {
                jacobian_nodes[c].resize(num_inputs);
            }
            int grad_node = diff_dag_node(dag, constraint_outputs[c], j, active, cache);
            jacobian_nodes[c][j] = grad_node;
        }
    }
    return jacobian_nodes;
}
```

Result: `jacobian_nodes[c][j]` stores the exact DAG node index for $\frac{\partial g_c}{\partial q_j}$. These nodes are seamlessly appended to the unified DAG, allowing simultaneous evaluation of all constraint residuals $g(q) \in \mathbb{R}^M$ and Jacobians $J(q) \in \mathbb{R}^{M \times N}$ in a single linear pass.

## 6. Robotics Context
The Jacobian is the core of manifold projection and differential inverse kinematics:
- **Gauss-Newton step:** $\Delta q = -J^+ g(q) = -J^T (J J^T)^{-1} g(q)$
- **Levenberg-Marquardt step:** $(J J^T + \lambda I) y = -g(q), \quad \Delta q = J^T y$

Our AD pass generates the exact $M \times N$ Jacobian required by the inlined C solver—completely eliminating manual error, finite-difference jitter, and tape allocation overhead.

## 8. Evolution & Optimization: Single-Scalar vs. Arbitrary Multi-Constraint Matrix AD

### A. Old Practice: Single-Constraint / Runtime Finite-Difference Perturbations
In early versions of Cudro:
1. **Single-Constraint Assumption ($M=1$)**:
   The compiler assumed a single scalar constraint ($g(q) \in \mathbb{R}^1$). The Jacobian was a flat 1D vector $\nabla g(q) \in \mathbb{R}^N$. Adding multiple constraints required either serial projections (which frequently oscillate or fail to find the intersection manifold) or heavy external matrix libraries.
2. **Exponential Matrix Branching**:
   Differentiating `MatMul(A, B)` naively applied the matrix product rule:
   $$\frac{d}{dq}(A \cdot B) = \frac{dA}{dq} \cdot B + A \cdot \frac{dB}{dq}$$
   Without analyzing whether $A$ or $B$ actually depended on $q_j$, both subtrees were recursively differentiated. For an $N$-DoF serial chain, this caused $O(2^N)$ binary tree explosion ($2^7 = 128$ branches per output on Panda 7), generating thousands of dead zero-nodes and overflowing the DAG.
3. **Runtime Finite Differences in JIT Kernel**:
   Because analytical Jacobians were not compiled into the generated C code, `project_single` computed Jacobians numerically at runtime using central/forward differences:
   ```c
   // OLD PRACTICE: N redundant DAG passes on EVERY iteration of LM
   for (int j = 0; j < num_inputs; ++j) {
       q_pert[j] += h;
       evaluate_dag(q_pert, g_pert); // Full DAG re-evaluation!
       out_J[c * num_inputs + j] = (g_pert[c] - g_curr[c]) / h;
       q_pert[j] -= h;
   }
   ```

---

### B. Updated Optimized Implementation: Arbitrary Multi-Constraint Symbolic AD
1. **Multi-Constraint 2D Matrix Synthesis ($M \ge 1$)**:
   `build_analytical_jacobians` takes arbitrary constraint lists $\{g_0, \dots, g_{M-1}\}$ and synthesizes a full $M \times N$ DAG node matrix. Every entry $J_{c,j} = \frac{\partial g_c}{\partial q_j}$ is an exact analytical node evaluated in-place without dynamic allocations or external tape overhead.
2. **Rodrigues Analytical Differentiation for `RotAxis`**:
   Arbitrary spatial revolute joints with skew axes are differentiated analytically using exact Rodrigues matrix derivatives:
   $$\frac{\partial R}{\partial \theta} = -\sin\theta \mathbf{I} + \sin\theta \hat{k}\hat{k}^T + \cos\theta [\hat{k}]_\times$$
3. **Activity Analysis (`compute_activity`)**:
   We scan the DAG forward in linear time. For serial kinematic chains and branching trees where joint $q_j$ appears in only one joint transform, at most one factor in `MatMul(A, B)` depends on $q_j$. The product rule collapses to:
   $$\frac{d}{dq_j}(A \cdot B) = \begin{cases} \frac{dA}{dq_j} \cdot B & \text{if } A \text{ active} \\ A \cdot \frac{dB}{dq_j} & \text{if } B \text{ active} \\ \mathbf{0}_{4 \times 4} & \text{otherwise} \end{cases}$$
   This reduces matrix derivatives from exponential $O(2^N)$ to a strictly linear $O(N)$ chain of matrix multiplies!
4. **Direct Analytical Jacobian Emission**:
   Exact derivative nodes are emitted directly into the unified kernel `evaluate_dag(q, out_g, out_J)`, allowing $g(q)$ and $J(q)$ to be evaluated in a single forward pass without finite differences.
